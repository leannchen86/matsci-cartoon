# Materials Science Cartoons

Interactive visual explanations of materials-science phenomena.

This repo collects small web-based explainers that turn materials-science concepts into inspectable visual demos. The goal is to make physical intuition easier to build through interaction, animation, and lightweight simulations.

## Projects

- `tapioca/` - tapioca ball starch-water microstructure, showing temperature, moisture, and storage-history effects.
- `prince-ruperts-teardrops/` - Prince Rupert's teardrop residual-stress and fracture demo.

## What This Demonstrates

- Interactive technical education for scientific concepts.
- Browser-based explainers that combine visual design with physical intuition.
- A portfolio pattern for teaching complex ideas through code, not only prose or slides.
